# vellum-lensed

Crafting tree browser for Star Citizen DataForge data, powered by [forge-lens](https://github.com/jonigirl/forge-lens).

## Requirements

Requires extracted DataForge XML files produced by [unp4k](https://github.com/dolkensp/unp4k) / unforge.
You must supply your own extracted files — no game assets are included.

## Install

```
pip install vellum-lensed
```

## Run

```
python -m vellum_lensed
```
